
# ゴール

アプリ内で打ち上げ花火製作シミュレーションゲーム
好きな花火をデザインして打ち上げ、鑑賞して楽しむブラウザゲームアプリ

# モード

## 製作モード

- 星（火薬と糊の合成物）や割火薬は用意されており、それをどのように配置するかを
- 1から作ることも可能
- 花火の種類分のプリセット…パーツの入れ替えを行なってカスタム

## 鑑賞モード

風や打ち上げの高さにより多少の揺らぎはあり、同じ種類の玉でも見た目に変化があるようにする

湖畔での打ち上げ　湖面に映り込んでほしい

### フリー

製作済みやプリセットの花火からランダムに打ち上げ

### ミュージック連動

指定された音楽ファイルを解析し、再生に合わせて、合う花火を選んで打ち上げ
