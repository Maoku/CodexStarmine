
# リニューアル方針

画面遷移や編集モードをより分かりやすいものにリニューアルする
許容角度・発火タイミングなど細かいパラメータは手動設定せず自動的に決まる
それらのパラメータを決める要素としては、仮想星の種類や位置によって決まるようにしたい

# モード選択

- 花火の作成・編集
- フリー鑑賞

# 画面遷移

## 作成・編集・削除画面

過剰な装飾を抑えた工房の棚に花火の玉を並べ、
新規作成か、既存玉の編集かを選ぶ
削除もできるように

## （新規作成の場合）初期設定画面

玉の大きさ、テンプレート（菊、牡丹とか）かブランクかを選ぶ

## 編集画面

半球・断面図・型物の表示タブは廃止し、1つの常設ワークベンチに統合する
- 緯度・経度で断面を選び星を置く感じにしたい（緯度・経度それぞれ４分割ごととか）
- 便利な配置として型物（ハート）や円形配置などをできるようにする

簡易確認は編集画面内の小窓に表示し、アニメーションで大まかな花火の広がりがわかるようにする（あくまでイメージなので実際の花火は表示しない）

編集画面は工房の作業台として表現し、金の飾り罫や過剰な発光などの装飾は抑える

### 編集画面構成
#### 制作工程ペイン

削除

#### レイヤーペイン

- 制作工程ペインのあったところまで広げる

#### 仮想星の部品皿

長押ししたら発火した時の広がりをバルーンで再生して欲しい

## 確認画面

フリー鑑賞と同じ湖面画面を使う
編集中の花火を単発ループ発射し、実際の再生結果をチェックできるようにする
確認は単一作品の再生チェック、フリー鑑賞は自動演目という役割に分ける
