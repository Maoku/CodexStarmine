# Codex Starmine user guide

[日本語版](USER_GUIDE.md)

Open the [English app](https://maoku.github.io/CodexStarmine/?lang=en). On first visit, the language follows `?lang=`, then your saved preference, then browser language. Use the **日本語 / English** control in the top-right corner to change it at any time.

## Create a firework

1. Select **Create fireworks** on the mode selection screen.
2. On the **Firework shelf**, select a built-in sample to edit a copy, edit a saved work, or select **New firework**.
3. Select a shell size and starting pattern, then choose **Start creating**.
4. In the editor, add preset, pattern, or manual layers; select virtual stars; and use the preview to compare the compiled launch result.
5. Choose **Check** to launch only the current work repeatedly with a fixed seed. Drag, touch, mouse wheel/pinch, WASD/arrow keys, Q/E, and the camera presets all work in this view.
6. Save the work to the shelf when finished.

## Image placement

Select an unlocked manual layer and choose **Generate from image**. Select the subject in the dialog, choose the placement range and point count, then apply the result. The generated points are ordinary manual points, so they can still be moved, deleted, and undone.

Images must be 20 MB or less and 24 megapixels or less after decoding. Processing stays in the browser; the image itself and its filename are never saved in a design.

## Save and restore

Use **Export** on the Firework shelf to download saved works as JSON, and **Import** to restore them. If an imported ID already exists, choose whether to skip it or replace the local work. Language changes never translate or rewrite a work name, layer name, description, JSON export, or schema version.

## Free viewing

Choose **Free viewing** from mode selection to watch an automatic show. Its density and camera presets can be changed while viewing. Saved works can appear in the show.
