# 新作花火調査に基づく仮想星拡張レポート

- 調査日: 2026-07-26
- 対象: CodexStarmine の「仮想星の部品皿」と打上結果
- 範囲: 公開されている花火の見え方、作品名、技術動向と、それを仮想表現へ置き換える方法
- 対象外: 実物の煙火の薬品、配合、製造、点火方法

## 1. 結論

次に増やすべきなのは、色違いの星ではなく、**発光する時間を設計できる星**である。

現行実装には14種類の花火プリセットがあり、柳、蜂、飛遊星、花雷、万華鏡、土星、蝶、小割まで揃っている。一方、全作品で再利用する内蔵仮想星は8種類で、違いの中心は色、寿命、落下、尾、弱いランダム明滅である。実在の新作花火で目立つ次の表現は、まだ十分に扱えない。

1. 一定周期で明滅する高輝度・多色の点滅
2. 星ごとに発光開始をずらす時差式・リレー式発光
3. 配置順や角度に沿って点灯・消灯するイルミネーション
4. 滑らかな混色ではなく、層が切り替わるような段階変色・反復変色
5. 終端だけがきらめく「光露」と、強く光る「輝」
6. 葉や雪のように速度を落として漂い、点滅しながら落ちる星
7. 一つの星が最後に火花や小粒へ分かれるポッピング表現

優先順位は次のとおりとする。

| 優先度 | 拡張 | 理由 |
| --- | --- | --- |
| P0 | 決定論的な発光エンベロープ、段階変色、終端閃光 | 点滅・光露・輝を同じ基盤で実現でき、星単体でも差が見える |
| P0 | 星ごとの位相と、配置に沿った時差制御 | イルミネーション、回転リング、グラデーション、ストップモーションへ展開できる |
| P1 | 葉落・雪・遊泳用の運動スタイル | 既存の柳・蜂・飛遊星も、初期配置だけでなく飛翔中の動きで差別化できる |
| P1 | 終端スパーク・小分裂 | ポッピングシャワーや花雷を視覚でも表現できる |
| P2 | 星単位の煙・尾の材質・線幅 | 写実性は上がるが、新作らしさへの寄与はP0/P1より小さい |

公開用プリセットを先に大量追加するより、P0の基盤を実装してから9種類前後の新しい内蔵星を追加する方がよい。現行のランダムな明滅を名前だけ変えて「時差式」や「ストロボ」と呼ぶと、実物との違いが大きくなる。

## 2. 調査結果の読み方

本レポートでは根拠の強さを分けて扱う。

- **確認済み挙動**: 煙火会社や主催者が、発光順、色、見え方を文章で説明しているもの
- **開発動向**: 競技会の受賞作名や作者コメントから、現在どの表現が試みられているか確認できるもの
- **実装提案**: 公開情報と現行コードを比較して、本アプリ向けに推論したもの

競技作品名だけでは内部構造や正確な動作を断定できない。そのため、「ストップモーション」「狐の尾」などは開発動向の手掛かりとして扱い、再現仕様は動画による別途の目視検証を前提とする。

## 3. 現行実装

### 3.1 花火プリセット

現行の花火プリセットは14種類である。

- 初期6種類: 菊、牡丹、冠、椰子、千輪、ハート
- 調査追加8種類: 柳、蜂、飛遊星、花雷、万華鏡、土星、蝶、小割

調査追加分は、長寿命と落下、枝状配置、時間差の子花、平面型物、複数色のグループなどを組み合わせている。既存テストでも、14種類の一意性、柳・蜂・飛遊星の差、花雷・万華鏡の二次開花、土星の扁平な環、蝶の色グループ、小割の子花が確認されている。

この追加によって**花火玉全体の構成**は大きく増えたが、複数作品で使い回せる**星そのものの発光方式**はほぼ増えていない。

### 3.2 再利用可能な内蔵仮想星

`BUILTIN_STAR_PRESETS` は次の8種類である。

| 現行の星 | 主な差 | 新作表現との関係 |
| --- | --- | --- |
| 赤の単色星 | 短い尾、赤系の色変化 | 基準となる点光 |
| 青から銀の変化星 | 3段階の色 | 段階変色の近似元 |
| 炭火引・赤から銀 | 長い炭火色の尾、煙 | 和火・引の基礎 |
| 金引星 | 明るい金尾 | 冠、柳の基礎 |
| 銀引星 | 明るい銀尾 | 銀竜、銀冠の基礎 |
| 白銀の点滅星 | `flicker` の大きい星 | 現状は周期点滅ではなくランダムな明るさ揺れ |
| 長寿命の冠星 | 長寿命、強い重力 | 冠、柳、落下系の基礎 |
| 時間差の子花星 | 短寿命、`child` 種別 | 二次開花は実際には星でなく子花レイヤー側が担当 |

各花火プリセットには外周星、芯星、子花星などの作品固有定義も加わる。ただし、それらは内蔵部品として横断利用する新しい発光タイプではなく、既存パラメーターを作品向けに派生させたものが中心である。

### 3.3 現行能力と不足

| 表現軸 | 現在できること | 不足していること |
| --- | --- | --- |
| 色 | 複数の `ColorStage` を時間補間 | 実物の層切替に近い段階変色、反復、保持時間 |
| 明るさ | 星全体の明るさ、色段階ごとの強度 | 編集UI、鋭い終端閃光、時間波形 |
| 点滅 | フレームごとのランダムな不透明度変化 | 周期、点灯率、位相、明滅の硬さ、色別制御 |
| 発火時刻 | レイヤー由来の小さい遅延と揺らぎ | 星プリセット由来の遅延、配置順・角度・半径との連動 |
| 尾 | 履歴線の長さと色 | 火花の粒立ち、尾の材質、実効線幅、尾だけの点滅 |
| 運動 | 抗力、重力、風による弾道 | 漂い、蛇行、渦、葉落、途中での減速変化 |
| 二次効果 | 子花レイヤーによる固定24星の小球 | 一つの星の終端スパーク、少数粒への分裂 |
| 煙 | 花火全体の開花煙 | 星ごとの煙量の反映 |
| 音 | `soft`、`crackle`、`deep` の構成比 | 星の終端分裂と同期する局所音 |

特に重要な実装上の差は次の3点である。

1. `emissionKind` は部品皿の分類、音の構成、一部の初速補正には使われるが、実行時の星オブジェクトへ種別として渡されない。金尾、銀尾、炭火尾の視覚差は、主に色・寿命・履歴長などの数値差である。
2. 現在の点滅は毎フレーム乱数で明るさを少し変える処理であり、強い光が明確に点灯・消灯するストロボではない。同じシードでもフレーム列を完全再現できない。
3. `trailWidth` と星単位の `smokeAmount` は型に存在するが、尾の実効線幅や星別の煙として十分には描画されていない。

このため、`emissionKind` の列挙だけを増やしても、新しい見え方にはつながらない。

## 4. 現実の新作・研究開発動向

### 4.1 時差式・イルミネーション・見かけの回転

[株式会社イケブンの公式商品紹介](https://www.ikebun.com/about/products/)は創造花火として、次の挙動を説明している。

- **イルミネーション**: パステルカラーが順に現れて消える
- **グラデーションボール**: 牡丹の開花後、流れるように星が順番に消える
- **ぐるぐる回転**: リング状の配置へ時間差の色変化を与え、回転して見せる

これは、星の軌道を実際に回転させなくても、**星ごとの位相と配置順**で運動感を作れることを示す。CodexStarmine の球面、リング、型物、手動配置と非常に相性がよい。

[三遠煙火](https://san-en-fireworks.com/)も、スマイル型物と色・明るさが変化する時差式花火を組み合わせた「いないいないばぁ」を新作型物として公開している。形状テンプレートと発光時系列を別々に持つ設計が有効だと分かる。

[2026年の立川まつり公式プログラム](https://hanabi.tokyo-tachikawa.org/wp-content/uploads/2026/07/%E5%85%AC%E5%BC%8F%E3%83%81%E3%83%A9%E3%82%B7-%E8%A1%A8%E9%9D%A2%E3%80%90%E7%A2%BA%E5%AE%9A%E7%89%88%E3%80%91.pdf)にも「時差式発光イルミネーション」が掲載され、緻密に計算された色合いと配置を「デジタルイルミネーション」と説明している。時差式は一社だけの特殊例ではなく、現行の鑑賞プログラムでも独立した見どころになっている。

### 4.2 高輝度・多色点滅

[加藤煙火の公式技術紹介](https://www.katoenka.co.jp/strobe-effects)は点滅花火について、研究開発を重ねて燃焼速度制御と経時変化抑制の技術を確立したと説明している。公開されている特徴は次のとおりである。

- 標準的な花火に対して高い光量
- 燃焼時間を制御
- 赤、緑、白、橙、桃、レモン、水色、紫の8色
- 難しいとされる水色でも、他色と同様の点滅を実現
- 点滅星そのものを製品として供給

さらに、[同社の製品一覧](https://www.katoenka.co.jp/en/products)には桃・レモン・青・白の「点滅葉落」があり、従来の葉落の燃焼時間を維持しながら明るく輝くと説明されている。「点滅」は白一色の一種類ではなく、色、燃焼時間、落下挙動を組み合わせる部品群として扱うべきである。

### 4.3 色、配色、中間色

[磯谷煙火店の公式紹介](https://isogaihanabi.com/isogai)では、実験と研究により明るく鮮やかな色を実現し、レモン、水色、オレンジなどの中間色を加えていると説明されている。また、「万華鏡」「光のオブジェ」「睡蓮の花」「ミルククラウン」「光の宝石」など、新しい配色・配列の創造花火を開発してきたとしている。

現行データは任意のRGB色を持てるため、色域そのものは大きな障害ではない。課題は、色を単純に時間補間するだけでなく、**段階的に切り替える、複数位置へ配る、時間差で見せる**ことにある。

### 4.4 光露・輝と終端表現

[JIS K 4800 の公開閲覧ページ](https://kikakurui.com/k4/K4800-2000-01.html)では、次のように区別される。

- **点滅星**: 強い光を間欠的に発する星
- **光露**: 引きの最後に星がきらきら光る現象
- **輝**: 引きの後、光露より強い光を放って消える現象

現行の「白銀の点滅星」は間欠発光というよりランダム揺れであり、光露・輝に対応する終端専用エンベロープもない。これらは形状を増やさなくても、星単体で違いが明瞭なため、最初の拡張に向く。

### 4.5 近年の競技作品が示す方向

[大曲の花火「新作花火コレクション2026」褒賞一覧](https://www.omagari-hanabi.com/cms/wp-content/uploads/2026/04/spring2026.pdf)によると、新作花火部門では次の作品が受賞している。

- 優勝: 「百鬼夜行〜未知との遭遇〜」
- 準優勝: 「厳冬に彷徨う狐の尾」
- 優秀賞: 「ストップモーション 2.0 ～光が描く奇しき世界～」
- 優秀賞: 「銀杏、色づく黄葉の舞」

作品名だけから挙動を断定はできないが、時間の断続、尾の動き、色づき、落葉のような動きを題材にした新作が評価されていることは確認できる。

[全国新作花火チャレンジカップ2025の主催者ページ](https://www.suwakanko.jp/story/hanabi-suwako/challenge-cup/archive2025/)には20作品と作者コメントが公開されている。そこには、色艶と形、イルミネーション、光の強弱、七変化、虹色、光の波紋、桜が散る動き、きらめく万華鏡などが並ぶ。受賞作も「華麗集」「桜花爛漫」「夢のスイカ」「光彩演舞」などであり、現在の新作は、単一の古典形状よりも**色・明暗・時間・形の組合せ**で作品性を作っている。

[大曲の第97回全国花火競技大会の成績発表](https://www.omagari-hanabi.com/results/2025competition)では、2025年の自由玉・創造花火に「青色の結晶」「陽炎」「細雪」、観光庁長官賞に「ポッピングシャワー」が並ぶ。これも結晶形、揺らぎ、細かな落下、粒がはじける表現を仮想星の候補として検討する材料になる。ただし、詳細な運動仕様は映像確認が必要である。

## 6. 推奨する増やし方

### 6.1 種類を直交する属性へ分解する

`emissionKind` に `strobe`、`relay`、`fallingLeaf`、`popping` を次々追加すると、金尾の点滅葉落、銀尾の光露、時差式の多色点滅などを表すために列挙値が爆発する。

仮想星を次の独立した軸へ分ける方がよい。

```ts
interface VirtualStarEffectProfile {
  colorTransition?: {
    mode: "smooth" | "step";
    repeat?: number;
  };
  lightEnvelope?: {
    mode: "continuous" | "strobe" | "terminalFlash";
    frequencyHz?: number;
    dutyCycle?: number;
    phase?: number;
    flashStrength?: number;
    flashDuration?: number;
  };
  motion?: {
    mode: "ballistic" | "fallingLeaf" | "wander" | "spiral";
    amplitude?: number;
    frequencyHz?: number;
  };
  secondary?: {
    mode: "none" | "spark" | "microBurst";
    count?: number;
    triggerTime?: number;
  };
}
```

既存の `emissionKind` は互換表示用として残し、新しい `effectProfile` を任意フィールドで追加する。フィールドがない既存作品は現在と同じ連続発光・弾道運動に解決すれば、v2〜v4の保存データを壊さず段階導入できる。

### 6.2 位相は星定義だけでなく配置から導出する

時差式の核は、一つの星の設定だけでなく、複数の星の発光順である。コンパイル時に各星へ `effectPhase` を確定し、次のマッピングを選べるようにする。

- `random`: イルミネーション状の不規則点滅
- `index`: 配置順のリレー
- `longitude`: リングや球面を横方向に回す
- `latitude`: 上から下、下から上へ流す
- `radius`: 中心から外、外から中心へ波紋を作る
- `group`: 型物の部位ごとに見せる
- `manual`: 手動点または画像由来点へ明示的な位相を付ける

現行の `SpatialColorMode` と似た考え方なので、編集UIでも「色の配り方」と「光る順番」を並列に説明できる。

### 6.3 色段階は補間方式と強度を編集可能にする

データには `intensity` があるが、現行の統合エディターでは主に星の選択しかできず、旧編集部でも色と時刻が中心である。新しい星を複製・調整できるようにするには、少なくとも次を公開する。

- 色段階の色、開始時刻、強度
- 補間方式: 滑らか / 瞬時
- 点灯 / 消灯の保持
- 最終閃光: なし / 光露 / 輝
- 点滅: 周期、点灯率、同期方法

薬品名ではなく見え方の語彙を使えば、仮想花火の範囲を保てる。

### 6.4 プレビューと本番を同じ評価関数にする

現在の部品皿プレビューは、色段階と「尾あり/点光/点滅/子花」の抽象図であり、時間変化を再生しない。新作星では静止画だけでは違いが分からない。

次の共通関数をプレビューと本番から利用する。

- `evaluateLightEnvelope(profile, normalizedAge, phase)`
- `evaluateColorStages(stages, normalizedAge, transitionMode)`
- `evaluateMotionOffset(profile, age, seed)`
- `evaluateSecondaryEvent(profile, previousAge, age)`

これにより、部品皿の短いループ、打上結果プレビュー、湖面での本番が一致する。

## 7. 最初に追加する内蔵仮想星

基盤実装後の初期セットとして、次の9種類を推奨する。色だけ違う項目を増やしすぎず、挙動の違いが一目で分かる構成にする。

| ID案 | 表示名案 | 主な挙動 | 主な参照 |
| --- | --- | --- | --- |
| `star-strobe-white-hard` | 強白点滅星 | 高輝度、明確な点灯/消灯 | 点滅星、2026年五重芯銀点滅 |
| `star-strobe-pastel` | 彩色パステル点滅星 | 桃→レモン→水色の段階色＋点滅 | 加藤煙火の多色点滅 |
| `star-relay-light` | 時差リレー星 | 配置位相に従って遅れて発光 | イルミネーション |
| `star-gradient-fade` | 流光グラデーション星 | 空間順に発光・消灯 | グラデーションボール |
| `star-kouro` | 銀光露星 | 尾の終端できらめく | JISの光露 |
| `star-teka` | 白銀輝星 | 終端で短く強烈に閃光 | JISの輝 |
| `star-repeat-change` | 紅青反復変化星 | 段階色を往復または反復 | 七変化、反復変化 |
| `star-strobe-leaf` | 点滅葉落星 | 長寿命、強い減速、横揺れ、点滅 | 加藤煙火の点滅葉落 |
| `star-popping` | はじけ子花星 | 終端で少数の火花へ分かれる | ポッピングシャワー |

色バリエーションは、最初から別IDを大量に作らず、上記を複製して色を変更できるようにする。ただし、加藤煙火が公開している桃・レモン・水色・紫などを、品質確認用のプリセット値としてテストへ用いるとよい。

## 8. 新しい花火プリセットへ展開する例

星の基盤を追加した後、花火玉は次の順で増やせる。

| 新プリセット案 | 使用する星・配置 | 現行との差 |
| --- | --- | --- |
| 彩色イルミネーション | 球面＋パステル点滅＋ランダム/グループ位相 | 現行万華鏡より細かな明滅 |
| 回転光環 | リング型物＋リレー星＋経度位相 | 土星の静的な環が回転して見える |
| 光の波紋 | 同心球/同心円＋半径位相 | 芯から外へ明るさが伝わる |
| ストップモーション | 型物/画像配置＋段階消灯＋離散位相 | 絵柄が段階的に変化して見える |
| 色づく黄葉 | 葉型物＋反復/段階変色＋葉落運動 | 蝶型物の静的輪郭から時間表現へ進む |
| 春雪・夏雪 | 芯＋点滅葉落＋短い浮遊 | 冠・柳より細かく明るい落下 |
| ポッピングシャワー | 球面＋ポッピング星 | 千輪や小割と異なる星単位の粒立ち |
| 光露変化菊 | 菊＋段階変色＋光露/輝 | 現行変化菊の消え際を強化 |

`FireworkPattern` を作品ごとに増やし続けるのではなく、配置テンプレート、星の効果、位相マッピングの組合せとして保存するのが望ましい。

## 9. 実装への影響

### 9.1 主な変更箇所

| 箇所 | 変更 |
| --- | --- |
| `src/data/firework.ts` | 任意の `effectProfile`、位相方式、段階変色方式を追加 |
| `src/data/starPresets.ts` | 新しい9種類の内蔵星を追加 |
| `src/core/burst/compiler.ts` | 星ごとの決定論的な `effectPhase` と二次効果計画を生成 |
| `src/core/burst/deriveVirtualBehavior.ts` | 星効果と配置から位相・運動幅・終端時刻を導出 |
| `src/core/particle/particle.ts` | 段階色と共通発光エンベロープを評価 |
| `src/render/fx/FireworkSystem.ts` | 周期点滅、運動オフセット、終端スパーク、星別煙を描画 |
| `src/render/preview/CompiledBurstPreviewRenderer.ts` | 本番と同じ効果評価を利用 |
| `src/ui/craft/StarLibraryPanel.ts` | 静止画でなく短い時間プレビュー、効果タグを表示 |
| `src/ui/craft/SelectedLayerInspector.ts` | 位相マッピングを選択 |
| 音声 | 終端スパークとマイクロバーストを局所音へ同期 |

### 9.2 互換性

- 新フィールドは任意にし、未指定時は現行挙動へフォールバックする。
- 既存の `flicker` は移行時に低振幅の `strobe` へ自動変換せず、従来の「揺らぎ」として残す。見え方が変わりすぎるためである。
- 真の点滅星は新しいプリセットだけで使い始める。
- `emissionKind` は当面残し、表示ラベルと旧音声互換に使う。
- 同じ設計とシードなら、フレームレートが違っても同じ位相になるよう、乱数ではなく時刻関数で点滅を評価する。

### 9.3 性能

現行上限は星6,000、煙1,400、尾頂点60,000である。ポッピングや終端スパークは粒子数を急増させるため、次を守る。

- マイクロバーストは親星1個あたり2〜6粒から開始
- 遠距離では終端スパークをシェーダー内の見かけだけに落とす
- `estimateBurstCost` に二次粒子数を含める
- プレビューでは本番と同じ効果を低密度で評価する
- 星単位の煙は全星へ出さず、量と画面寄与に基づきサンプリングする

## 10. 検証方針

### 10.1 自動テスト

1. 同一設計・同一シードで、位相、点滅、二次効果が同じになる
2. フレーム刻みが異なっても、指定時刻の発光値が一致する
3. `step` 変色は境界前後で色が補間されない
4. 光露と輝は終端時刻だけ発光し、輝の最大強度が高い
5. 経度位相ではリングの点灯順が一方向へ進む
6. 半径位相では中心から外へ順に発光する
7. 古いv2〜v4作品のコンパイル結果が許容範囲内で変わらない
8. 二次粒子を含む負荷見積りが描画上限を越えると警告する

### 10.2 目視基準

- 点滅星が「ちらつき」ではなく、肉眼で点灯と消灯を区別できる
- 桃、レモン、水色の点滅が白へ潰れず見分けられる
- 回転リングは粒子自体を不自然に回さず、発光順だけで回転して見える
- 光露は余韻、輝は一瞬の強い終止として識別できる
- 葉落は柳の単純な垂下と異なり、横揺れと減速が見える
- ポッピングは千輪の大きな子花と異なり、親星の終端で細かくはじける
- 部品皿、打上結果プレビュー、湖面表示の時間表現が一致する

## 11. 推奨ロードマップ

### Phase 1: 発光基盤

- 決定論的な発光エンベロープ
- `smooth` / `step` 変色
- 光露、輝
- 強白点滅、彩色パステル点滅、反復変化の内蔵星
- 時間再生できる部品皿プレビュー

### Phase 2: 時差式

- 星ごとの `effectPhase`
- index、経度、緯度、半径、group の位相マッピング
- 時差リレー、流光グラデーションの内蔵星
- 彩色イルミネーション、回転光環、光の波紋の花火プリセット

### Phase 3: 運動と二次効果

- 葉落、wander、spiral の運動スタイル
- 終端スパーク、マイクロバースト
- 点滅葉落、はじけ子花の内蔵星
- 色づく黄葉、降雪、ポッピングシャワーの花火プリセット

### Phase 4: 精密化

- 星単位の煙
- 尾の実効線幅、粒状尾、尾だけの点滅
- 動画参照による2025〜2026年競技作品との目視比較
- 観客距離、画面解像度、スマートフォン性能に応じたLOD

## 12. 採否判断

最初の実装対象は **Phase 1とPhase 2を一続きの機能として扱う**のがよい。Phase 1だけでも星は増えるが、現実の新作花火で強い傾向にあるイルミネーション、回転、波紋、ストップモーションへ届くには、星ごとの位相が必要だからである。

逆に、次は初回から行わない。

- 競技作品名ごとの専用 `FireworkPattern` 追加
- 色違いだけの星を大量登録
- 毎フレーム乱数による点滅バリエーション追加
- 実物の薬品・製造法を模した入力項目
- 動画確認なしに、2026年受賞作の正確な再現をうたうこと

採用案は、現在の14花火を壊さず、9つの星挙動を追加し、その組合せで少なくとも8つの新作系花火へ展開できる。種類数を増やすだけでなく、ユーザーが既存の型物、画像配置、球面配置へ新しい時間表現を持ち込める点が最大の利点である。
