
# 画像から仮想星配置

[English](IMAGE_TO_STARMINE.en.md)

玉内配置ワークベンチで手動レイヤーを選択しているときだけ「画像から生成」ボタンを表示する。画像選択後は点指定ダイアログを開き、モデル方式では被写体の範囲または被写体点、古典方式では加えて除外背景と残したい特徴を指定してから、現在の切断面へ編集可能な手動配置点として反映する。

## 確定仕様

- 点指定式ではSlimSAM解析用画像を最長辺1024pxへ縮小する。即時fastプレビューは最長辺256pxを維持する。いずれもブラウザ内だけで解析し、外部送信・保存データへの埋め込みは行わない。
- デコード前は20MB、デコード後は24メガピクセルを上限とし、EXIF向きを反映した `ImageBitmap` から表示用・解析用データを作る。
- 被写体点は1〜3点、背景除外点と特徴点は各0〜5点とする。SlimSAM・alphaのモデルプロファイルでは「被写体を囲む」「被写体」だけを表示し、fast・grabcutの古典プロファイルでは特徴と背景除外も表示する。特徴点は指定位置への仮想星配置だけに使う。
- 点は元画像基準の正規化座標で保持する。CSS表示寸法、ズーム、パン、devicePixelRatioが変わっても座標は変えない。
- マスクはWorker内で生成する。有効alphaを最優先し、不透明画像は `SlimSAM WebGPU (fp16) → SlimSAM WASM (q8) → fast` の順で実行する。各高精度backendの画像エンコードは30秒、マスクデコードは15秒で打ち切り、操作全体を停止させない。WorkerまたはOffscreenCanvasが使えない場合はfastをメインスレッドで実行する。
- SlimSAMは画像ごとに1024px埋め込みを1回だけ計算し、点・矩形の変更時はデコーダーだけを再実行する。3候補をプロンプト充足、predicted IoU、閾値安定性、矩形・境界整合、前回マスクとの連続性で採点する。
- 選択候補は0.35〜0.65の閾値を探索し、正点・負点制約を修復してから適応的に連結成分を整理する。順序付き輪郭を累積弧長で等間隔再サンプリングし、採用マスクの外接矩形を安全半径0.94へ収める。
- 特徴点はユーザーが指定した位置そのものへ仮想星1点だけを配置する。自動拡散（周辺エッジへの配点）は行わない。色は特徴点周辺（最小辺の6%半径）のマスク内画素の中央値色を使う。外形へは常に目標点数−特徴点数（特徴は最大5点）を割り当て、推論マスクは輪郭配置専用とする。
- ダイアログは `role="dialog"`、`aria-modal="true"`、フォーカストラップ、Escape取消、元ボタンへのフォーカス復帰を持つ。画像キャンバスは矢印キー、Enter、Spaceでも操作できる。
- 確定前はdraftとUndo履歴を変更しない。確定時に開始時のレイヤーと切断面を使い、レイヤーの存在、手動種別、ロックを再検証して、成功時だけ1回の `updateIntent("画像から配置")` を行う。
- 外周画素の中央値から背景色を推定し、画像外周から洪水充填で「背景色に近く外周へ連結した領域」を背景とする。被写体に囲まれた背景色領域（白背景上の白い服など）は被写体側に残る。
- 被写体の連結成分を背景コントラストの合計で採点し、主要成分に対して弱い分離成分（壁の陰影の帯、切れた小片など）は配置対象から除外する。
- 画像の切れ目（被写体が画像端に接する箇所）は輪郭とみなさず、点を置かない。
- 整形後の被写体マスク全体を決定的なメディアンカットとOKLab距離で最大8色へ量子化し、画素ラベルを保持する。3×3多数決、小領域統合、外形近傍除外、短線除外の後、異色ラベルが接する辺を順序付き内部境界へ追跡する。
- 配置範囲は「輪郭のみ」「輪郭＋内部境界」「輪郭＋内部境界＋内部」の3モード。既定は「輪郭＋内部境界」で、特徴点を先に差し引いた予算を外形45%・内部境界55%へ配分する。充填モードは外形30%・内部境界40%・内部30%を基準とし、候補不足分を決定的に再配分する。
- 内部境界点の色は境界両側の代表色を交互に割り当て、内部点と特徴点も同じ最大8色パレットを使う。代表色ごとに既存ライブラリの色へ寄せない画像由来の仮想星を生成し、「単色星」「変化星」「引星」から共通の発光方式を選べる。輪郭色は画像の代表色とは分け、既存ライブラリから選んだ1種類の仮想星を全輪郭点へそのまま指定する。
- 目標点数は8〜2048点、点指定ダイアログの既定は1024点。スライダー（8点刻み）と数値入力を双方向同期し、PageUp/PageDownでは128点ずつ変更する。同一画像・同一指定・同一設定の結果は決定的にする。
- 外形・内部境界・内部・特徴は、仮表示上でそれぞれシアン・マゼンタ・黄・ライムに分ける。この役割色は確定後の仮想星色とは独立し、`pointKinds` と診断点数を常に点列と揃える。
- 減色、境界追跡、配点は専用Workerで実行し、マスクと特徴指定が同じ間は解析結果を再利用する。requestIdとmask revisionが最新の結果だけを採用し、Worker非対応時は描画機会を挟んだ同期処理へフォールバックする。
- 処理状態はダイアログ下部へ集約し、モデル準備、推論、減色、境界追跡、配点をスピナーと進捗で表示する。取消は常時有効、配置は最新結果がreadyになり制約を満たした場合だけ有効にする。
- 配置先は現在の切断面で、生成結果は通常の `ManualLayerPoint` とする。移動、削除、仮想星の置換、Undo/Redoを既存操作のまま利用できる。
- 暗色補正はオン／オフを選べる。既定オンでは黒・灰色などの無彩色を銀系へ、暗い有彩色を色相を保って増光してから、その補正色で画像由来の仮想星を生成する。オフでは取得した代表色をそのまま使う。別指定した輪郭点には補正をかけず、その既存星IDをそのまま使用する。同じ発光方式とRGB色の画像由来星は再利用し、未使用になった画像由来星は作品から除去する。
- 既存の「生成方法」（置換／追加）を共有する。
- ファイルサイズは20MB以下とし、被写体として8点以上を抽出できない画像はレイヤーを変更せず通知する。
- 保存形式はschema v4を維持する。

## マスクプロバイダ

2026-07-18にSlimSAMを高精度プロバイダとして採用した。`@huggingface/transformers` 3.8.1をWorker内で動的importし、通常起動bundleから分離する。既定は `auto` で、`?segmentation=fast` を付けると回帰比較用にfastを強制できる。

- モデル: `Xenova/slimsam-77-uniform`
- 固定revision: `5850ab45f587c112167512ffef949107115e26a0`
- WebGPU: fp16画像エンコーダー／プロンプトデコーダー
- WASM: q8画像エンコーダー／プロンプトデコーダー
- ライセンス: Apache-2.0
- 配布量: モデル34,518,953 bytes、ONNX Runtime WASM 32,794,766 bytes
- 完全なファイル名、容量、SHA-256: [`public/models/slimsam-77-uniform/5850ab45f587c112167512ffef949107115e26a0/manifest.json`](../public/models/slimsam-77-uniform/5850ab45f587c112167512ffef949107115e26a0/manifest.json)

モデル、設定、WASM、ライセンスは同一オリジンから配信し、`allowRemoteModels = false` を設定する。取得スクリプトは固定revisionと固定SHA-256だけを受理し、production buildも全資産のhashと容量を検証する。有効alpha画像ではモデルをロードしない。
