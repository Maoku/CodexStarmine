
# 画像から仮想星配置

玉内配置ワークベンチで手動レイヤーを選択しているときだけ「画像から生成」ボタンを表示する。ボタンから画像ファイルを選択すると、ブラウザ内で被写体のシルエットと代表色を抽出し、現在の切断面へ編集可能な手動配置点として反映する。

## 確定仕様

- 画像は最長辺128pxへ縮小してブラウザ内だけで解析し、外部送信・保存データへの埋め込みは行わない。
- 外周画素の中央値から背景を推定し、背景との差とアルファを使って被写体候補を抽出する。
- 目標点数は8〜240点、既定96点。同一画像・同一設定の結果は決定的にする。
- 配置先は現在の切断面で、生成結果は通常の `ManualLayerPoint` とする。移動、削除、仮想星の置換、Undo/Redoを既存操作のまま利用できる。
- 画像色は最大4色へ量子化する。近い既存の仮想星を優先し、必要な場合だけ `star-image-*` 派生星を追加する。
- 既存の「生成方法」（置換／追加）を共有する。置換後に未参照となった画像由来の派生星は除去する。
- ファイルサイズは20MB以下とし、被写体として8点以上を抽出できない画像はレイヤーを変更せず通知する。
- 保存形式はschema v4を維持する。

## 実装・確認記録

- 実装日: 2026-07-16
- サンプル: [`reference/latte.png`](reference/latte.png)（400×400、透過PNG）
- 実測: 128×128へ縮小後、既定設定で96点、最大断面半径0.8534、4色へ割当。2回の抽出結果は完全一致した。
- エディター統合確認: 96点生成、成功通知、Undoで0点、Redoで96点へ復帰、schema v4維持、画像本体・ファイル名の非保存を確認した。
