# フッタ

## メッセージ表示

一時的なステータスメッセージやTIPSメッセージを表示するエリアを追加
Redoと保存して棚ボタンの間に配置

## 湖面で確認

右下

## 保存して棚

湖面で確認と同じように目立つ装飾のボタンに
未保存の変更ありはボタンの色でその役割を示す（未保存の変更になったら灰色→青色にするとか）

## 負荷予測

以前あった仮想星の数をベースとした負荷予測が出なくなっているので表示

# 玉内配置ワークベンチ

## 拡大縮小

スライダーを追加
玉の仮想星の操作をしやすくする

## 玉の回転

ギズモのX,Y,Zの位置にボタンを置く
ボタンを押すと面になる Z ならXY平面、YならXZ平面が映るように

玉の左側と下部に回転スライダを置いて、玉が３次元的に見えるようにしたい

## 操作面

段階スライダーで選択

# 選択レイヤー

ペインタイトル位置にレイヤー名のエディットを置く
選択レイヤーの表示域を増やす
