
# タイトル画面

- 背景に花火が打ち上がっている様子を映して欲しい

# 玉内配置ワークベンチ

- 右上に玉を三次元的に見てどの断面を操作しているかわかるようにギズモ付きの玉表示をして欲しい

## 規定

- 断面の向きと断面位置は使わない。表示しない

## 型物

- 型物はスケール指定ができる
- 選択している断面の位置に置かれる
- 選択している断面のサイズ以上にはならないようにする
- ハートを指定しても円形で打ち上がっている　玉の中の位置が反映できているかを確認
- 星形や四角など幾何学模様をいくつか追加してほしい

## 手動

- クリック位置と仮想星が置かれる位置がズレているので修正して
- 円周配置や直線配置など配置支援の機能が欲しい

# 配置全体の簡易確認

- 実際に打ち上がった時と簡易確認の動きが乖離している

# 確認

湖面で確認シーンでもフリー鑑賞同様に視点を変えられるようにしてください

# 鑑賞シーン

- 月は消して欲しい
- 湖面の繰り返しパターンが見えないように品質向上してほしい
