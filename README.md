# Codex Starmine

自分でデザインした打ち上げ花火を、湖畔の夜景で鑑賞するブラウザシミュレーションです。

Phase 6.5 まで実装済みです。菊・牡丹・冠・椰子・千輪・ハートを3号・5号・10号で仕立て、仮想星を玉皮の内部へ配置してから、湖畔の単発打上または自動構成のスターマインで鑑賞できます。

## 遊び方

1. 「製作」でプリセットを選ぶか「一から作る」を選ぶ
2. 部品皿の仮想星を外周・芯・型物・子花レイヤーへドラッグし、半球組立・断面・型物配置で玉内を整える
3. 「簡易確認」で色列・方向・発火タイミング・描画負荷だけを確認する。ここでは完成した開花形状は表示されない
4. 必要ならUndo/Redoや構成A/Bで配置差を比較し、「制作を確定」する
5. エディターを離れて「湖畔で打ち上げる」を選ぶと、そこで初めて完成形を鑑賞できる
6. 「フリー鑑賞」へ切り替え、演出密度を選んで保存作品を含む自動ショーを楽しむ
7. フリー鑑賞では画面をドラッグして見回し、右ドラッグで平行移動、ホイールやピンチで花火の内側まで接近する。キーボードはWASD／矢印で前後左右、Q/Eで上下、Shift併用で高速移動する。プリセット視点の選択と「元の位置に戻る」も利用できる

保存作品はブラウザの `localStorage` にv2形式で保持されます。旧v1作品は全件を検証できた場合だけv2へ自動移行し、v1データ自体は削除しません。音は最初のクリックまたはキー入力後に有効になり、「音の距離感」で物理遅延と即時寄りの演出を調整できます。

## 開発

```bash
npm install
npm run dev
```

品質確認:

```bash
npm run lint
npm run test:run
npm run build
```

設計とフェーズごとの実装範囲は
[`Docs/IMPLEMENTATION_PLAN.md`](Docs/IMPLEMENTATION_PLAN.md) を参照してください。

## 構成

- `src/core`: レンダリング非依存のシミュレーション
- `src/render`: three.js のシーンと描画効果
- `src/audio`: 効果音と音楽解析
- `src/data`: データモデル、プリセット、永続化
- `src/modes`: 製作・フリー鑑賞・音楽連動モード
- `src/ui`: UI コンポーネント

## 現在の実装範囲

- 湖畔夜景、星空、月、山影、波立つ湖面、HDR・ブルーム
- 6種類の花火、3サイズ、芯、色変化、尾、子花、打上揺らぎ
- 距離遅延付きの合成音、風下へ蓄積する煙、開花時の環境照明
- 製作デザインの保存・読込・複製・削除
- 8種の仮想星、外周・芯・型物・子花レイヤー、半球組立・断面・型物配置・簡易確認
- 100件Undo/Redo、構成A/B、最大粒子数・尾・子花を含む描画負荷診断と自動簡略化
- 固定assembly seedと本番launch seedによる再現可能な内部配置・意図を壊さない打上揺らぎ
- v1保存作品を残したまま行うv2非破壊移行
- ShowCue タイムラインによる単発・連続・連発・スターマインとフリー鑑賞
- フリー鑑賞の自由カメラ、4つのプリセット視点、湖畔固定席へのリセット
